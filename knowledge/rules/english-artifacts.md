# English durable artifacts

- Do write OKF entries, `knowledge/` docs, CHANGELOG macro entries, code comments meant as durable guidance, and agent instruction files in **English**.
- Do keep user-facing product UI strings localized (`en-US` / `pt-BR`).
- Do keep `README.md` (English) and `README.pt-BR.md` in full parity when either changes.
- Do not invent a second language for agent-facing knowledge trees.
- See also: `knowledge/product/documentation-system.md`
