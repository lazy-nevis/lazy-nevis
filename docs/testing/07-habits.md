# 07 — Habits editor and logging

1. New habit → Icon. **Expected:** a dropdown grid with 4 large icons per row; the trigger shows the
   chosen icon in the habit tone.
2. Targets: hover the info icon and column labels. **Expected:** help tooltips. Add targets up to
   5/5 (button disables). A `check` target hides unit/goal and shows a hint.
3. Remove a target with the trash icon (disabled when only one remains).
4. Add two reminder schedules; configure them as in script 06.
5. Delivery Default/Custom behaves like reminders.
6. Save. **Expected:** the habit card shows the icon; the Dashboard habits widget shows it too.
7. Log the habit with a backdated time using the date-time picker. **Expected:** the log appears at
   that time in the habit history.
