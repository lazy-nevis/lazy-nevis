# 03 — Dashboard overview

**Setup:** at least one session today, one checklist item due today, one reminder today, and two
or more habits.

1. Open Dashboard. **Expected:** hero cards (Sessions, Pomodoro, Checklist), stats row, habits
   preview (max 3 + "see all"), mini calendar with today highlighted, today's checklist and
   reminders.
2. Hover a widget, drag it by the grip handle to another position, reload the window
   (⌘R). **Expected:** the new order persists.
3. Click the resize control on a widget repeatedly. **Expected:** it cycles small → medium → large
   width on wide windows; the choice persists.
4. Click "Reset layout". **Expected:** default order and sizes return.
5. Focus a grip handle with Tab, press Space, arrow keys, Space. **Expected:** keyboard reorder works.
6. Start a session from the hero card. **Expected:** stats update without a manual refresh.
