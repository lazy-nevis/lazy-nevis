# 10 — Settings → Alerts and delivery

1. Open Settings. **Expected:** no separate delivery/notifications tab.
2. Alerts tab: below the alert settings, a "Reminders, habits & Pomodoro delivery" section with one
   channel card per type (tiles for notification / fullscreen / sound, sound select, test button).
3. Disable the Sound tile. **Expected:** the sound select disables.
4. Press "Test delivery" for each type. **Expected:** delivery uses the configured channels.
5. General tab: "Week starts on" control is present and changes the calendar and pickers.
6. Restart. **Expected:** all choices persist.
