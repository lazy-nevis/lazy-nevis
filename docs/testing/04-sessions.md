# 04 — Sessions

1. In the sidebar Plan group, confirm **Sessions** appears before Checklist and opens `/sessions`.
2. Start a focus session. **Expected:** the header session pill appears; clicking it opens Sessions.
3. Pause, resume, stop. **Expected:** today's list updates, totals are correct.
4. Trigger the start-session modal from the command palette (⌘K → start). **Expected:** the modal
   opens from any screen, not only Sessions.
